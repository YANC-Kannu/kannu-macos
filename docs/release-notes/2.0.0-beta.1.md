## Kannu 2.0.0 beta 1 — Horus

**This is a beta, for testers.** It is signed and notarized like a release, but Kannu's automatic
updates never offer it: you get it only by downloading the DMG below. When 2.0.0 ships, your Kannu
updates itself to it as usual.

Requires macOS 14.6 or later. It installs over 1.3.4 or a 1.4.0 beta and keeps your settings.

### What you get

2.0 makes the notch the front door and **Brain** the room behind it.

- **Brain.** Settings becomes seven product pages (Agents, Security, Usage, Tasks, Timer, Notes and
  Clipboard), each opening on its live state with its settings below. The other settings sit
  behind one Settings row. Paper in light and ink in dark, set in Geist. Full screen (⌃⌘F), a menu
  bar of its own (Go ⌘1–⌘7, View, File › New Task ⌘N) and sidebar badges for what needs you.
- **Tasks.** Jira Cloud, GitLab, GitHub, Linear, Todoist and Apple Reminders beside your own tasks,
  all read-only. Active, Done and Archived tabs with Find and a Tag filter, the task you open beside
  the list on a wide window, New task (⌘N), the timer and Time to log, and an archive that tidies
  itself.
- **Tags.** `#tag` and `@time` typed in a task's name, chips and colours, a `#tag` search that finds
  the whole tag, and one Tag filter in Brain and in the notch.

Also new since 1.4.0 beta 3:

- Onboarding, the clipboard panel and the LocalSend picker in Brain's look, and Geist in the notch.
- The notch stays open while your pointer is on it, and hovering opens it after 0.3 s.
- Claude's usage gets a card per organization, limit bars that expire on time, and token totals
  without cache re-reads.
- Kannu's agent hook no longer writes a prompt to disk, even for a moment.
- The headphones animation plays, and pinned clipboard images survive a relaunch.
- A new eye icon, and an install window to match.

### What changes when you update

- **Settings is now Brain**, and a setting's path reads like **Brain › Settings › General**.
- **A short welcome** opens once, the first time 2.0 runs after an update.
- **The minimal UI mode is gone.** If you used it, **Show media controls in Dynamic Island** is
  turned on for you, so the closed notch keeps your music.
- **Hovering opens the notch after 0.3 s** instead of 1 s, unless you set your own value.

### Please try

- **Updating.** Install this DMG over 1.3.4 or a 1.4.0 beta. Once the Terms of Use are accepted,
  the welcome should open once. Return or Escape closes it, and it should not open again after you
  quit and reopen Kannu.
- **A fresh install,** in a second macOS user account: the Terms, then onboarding with no pop-ups,
  one macOS dialog per **Allow** and none for **Not now**, the music only after **Finish**, and no
  welcome window.
- **Brain,** in light and dark: open it with ⌘, and from the notch's brain icon, then go through
  the pages with ⌘1–⌘7. Enter full screen with ⌃⌘F, then press ⌘W: Brain should leave full
  screen, close, and leave no empty Space.
- **Tasks:** press ⌘N on any page and type `Ship notes #launch @3pm`. The chips, the tag and the
  reminder should all come out right. Search `#launch`, try the Tag filter here and in the notch's
  filter menu, and widen the window with a task open.
- **With an agent working:** the light in the notch, the yellow dot on Agents while it waits for
  you, and a timer running beside it.
- **CPU:** leave Brain on Agents while an agent works, then close it, minimise it or leave it full
  screen in another Space. Kannu should go quiet in Activity Monitor.

### Going back

Please stay on the beta until 2.0.0 ships. It upgrades Kannu's agent hook and changes some stored
settings, and going back to 1.3.4 or a 1.4.0 beta over them has not been tested. If you have to,
tell David first.
